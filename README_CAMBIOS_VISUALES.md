# Gestión visual de cambios

## Añade

- Columna 🟢 Modificado
- Columna Último cambio
- Filtros:
  - Solo modificados hoy
  - Modificados últimos 7 días
  - Modificados últimos 30 días
- Contador de expedientes modificados

Compatible con:
- exportación Excel exacta
- filtros existentes
- columnas configurables
