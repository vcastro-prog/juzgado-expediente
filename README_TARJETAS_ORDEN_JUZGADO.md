# Tarjetas ordenadas por número de juzgado

Cambio aplicado:

- La tabla de carga por juzgado mantiene el orden por carga/porcentaje.
- Las tarjetas visuales se ordenan por `Nº Juzgado`.
- Esto permite localizar siempre cada juzgado en un orden estable.
